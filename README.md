# Around · Sprint 19

Around es una aplicación de fotos que permite crear una cuenta, iniciar sesión, editar el perfil, publicar y eliminar tarjetas y dar me gusta.

- [Aplicación web](https://around-sprint19.ddnsfree.com)
- [API](https://api.around-sprint19.ddnsfree.com)

## Tecnologías

React, React Router y Vite en el frontend. Node.js, Express, MongoDB y Mongoose en el backend, con autenticación JWT.
La aplicación se aloja en Google Cloud con Nginx, PM2 y certificados de Let's Encrypt.
